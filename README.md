## 日期與平均方法

- CSV 保留原始文字，避免日期格式化造成時分秒遺失；Excel 保留原始日期值。
- 支援中文上午／下午、指定日期排列，以及獨立的日期與時分秒欄。欄位區顯示前三筆解析時間及解析失敗筆數；若全部為午夜會提示檢查欄位。
- 「CO₂ 24 小時平均圖」為獨立圖表模式，只在選取此模式後顯示。依所選期間與 CO₂ 數值篩選後的原始觀測，按 00–23 小時計算逐筆算術平均；不受每日／每小時彙整設定影響。這是觀測值加權平均，並非各天等權平均。
- 外站開關位於資料欄位區；關閉後重算且排除外站資料。
- 內外同指標使用相同顏色，外部使用粗虛線；圖例顯示線段而非填色矩形。
- CO₂ 24 小時平均已與實際原始 CSV 依時間欄另行計算的各小時平均逐項核對；每日／每小時彙整不影響結果。

- 直接在瀏覽器讀取 `.xlsx`、`.xls`、`.csv`（資料不會上傳到伺服器）

- 自訂開始／結束時間，將 30 秒資料以 5 分鐘、15 分鐘、每小時或每日平均彙整

- 可對溫度、濕度、CO₂ 各自設定上下限篩選（含邊界），並選擇連續資料、逐日圖或三項合併圖；外部資料以同色粗虛線呈現
- 另提供 SCD30 CO₂ 的 24 小時平均圖，將所選區間內相同小時的觀測值平均
- 可下載目前圖表 PNG 與彙整後 CSV，便於研究可重現性紀錄

## 資料格式建議

每一列代表一個時間點；第一列為欄位名稱。至少需有一欄可解析的時間欄位，以及至少一個數值欄位。日期建議使用 `YYYY-MM-DD HH:mm:ss`，可避免不同電腦的地區日期格式誤讀。

> 論文或報告請記錄使用的時間範圍、彙整尺度、排除條件與氣象站位置／資料來源。網頁不會自動插補缺失資料。
